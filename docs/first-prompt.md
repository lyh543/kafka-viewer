整体 UI：

类似于桌面应用，有一排顶栏：连接、关于、等等
顶栏下面是主视图，主视图左边是连接的栏（可收缩到最左侧的一条），主视图右边支持多 tab 显示 kafka 的数据。也需要支持标签页管理，后续需要支持分屏（三分屏、或者 2x2分屏）
有一个底栏，你思考一下展示什么信息比较好

数据需要持久化到本地，密码需要加密存储。前期可以先明文存储

用户使用流程：

1. 先是在打开项目窗口，创建项目、打开最近项目、从文件资源管理器选择项目文件夹，创建项目时需要指定项目文件夹和项目名（默认在 ~/KafkaViewer/projects/xxx），进入主窗口
2. 在主窗口的顶栏有一个下拉菜单叫文件。打开有新建项目、打开项目、打开最近的项目、关闭项目、管理连接、设置。点击连接，弹一个管理连接弹窗。弹窗左侧是当前连接列表，右侧是连接信息。连接列表上面有三个图标按钮，悬浮时可以看到 tooltip 分别是新建连接、复制连接、删除连接。
  * 设置按钮第一阶段先不实现，后续可以添加一些用户设置，比如主题颜色、界面语言、放缩比、缓存大小（每个页面的缓存大小默认200MB、总的缓存大小2GB）。
2. 用户点击新建连接，在右侧的连接信息中输入 kafka url，选择身份验证，提供一个测试连接的按钮，返回测试结果。再提供取消、保存、保存并关闭三个按钮
3. 关闭弹窗后，主窗口左侧是树形结构。
  * 展示连接-下一层是主题list、消费者组list。主题list下一层是每个主题，消费者组list下一层是每个消费者组。双击主题后，标签中打开主题状态标签页；双击消费者组后，标签中打开消费者组状态标签页。
  * 树形结构每个节点都支持右键操作。
    * 比如连接节点支持编辑连接、移除连接、刷新连接下的所有数据；
    * 主题 list 节点支持刷新主题列表、创建主题等；
    * 主题节点支持查看主题数据、查看主题状态；
    * 消费者组 list 节点支持刷新消费者组列表、创建消费者组等；
    * 消费者组节点支持查看查看消费者状态、重置偏移量等。
4. 主题状态标签页展示主题的基本信息（分区数、副本数、ISR、leader 等），以及每个分区的状态（分区号、leader、副本列表、ISR 列表、当前偏移量、log end offset 等）。页面上方是一排图标按钮。提供一个刷新按钮，刷新主题状态。需要支持自动刷新，用户可以设置刷新频率（比如 5s、10s、30s、1min、2min、5min等）。刷新功能可以封装为一个通用组件，并且支持持久化用户刷新的配置，每个连接的每个页面使用独特的刷新配置。提供一个按钮数据，点击以后打开这个主题的数据标签页（如果已经存在则切换到该标签页）。
5. 数据标签页显示数据。打开时就默认加载最后100条数据。支持筛选（键类型、值类型、键等于/不等于/包含/正则，值等于/不等于/包含/正则，起点：最新、从开头、过去一小时、今天、昨天、具体日期、使用者组、最新偏移量前X条、limit：主题记录号、日期、主题最大大小、分区记录号、分区最大大小）。上方是一排图标按钮。提供一个写入数据的按钮，打开一个写入数据弹窗。提供一个刷新按钮，刷新数据。需要支持自动刷新。
  * 由于 Kafka 本身的协议是非常底层的，它不支持像 SQL 数据库那样在服务端进行复杂的关键词或正则筛选。所以对于kafka服务端支持的筛选，需要传参给服务端筛选；对于kafka服务端不支持的筛选，需要在后端对字段模式匹配筛选后发给前端。后端可以按 分区+offset_range 对数据作内存缓存，缓存大小限制200MB，可以在设置里修改。
6. 消费者组状态标签页展示消费者组的基本信息（成员数、分配策略等），以及每个成员的状态（客户端ID、所属主机、分配的分区等）。页面上方是一排图标按钮。提供一个刷新按钮，刷新消费者组状态。需要支持自动刷新，用户可以设置刷新频率（比如 5s、10s、30s、1min、2min、5min等）。刷新功能可以封装为一个通用组件。提过一个按钮，点击以后打开这个消费者组的数据标签页（如果已经存在则切换到该标签页）。
7. 主窗口的顶栏添加一个关于下拉菜单叫按钮栏。按钮栏里有检查更新、关于。
  * 点击后弹出一个关于窗口，展示项目的基本信息（项目名、版本号、作者等），以及项目的 github 地址等。
  * 检查更新从 github 上检查最新版本，如果有新版本则提示是否下载并安装。

前端使用 ant design。请阅读 https://ant.design/llms-full.txt 并理解 Ant Design 组件库，在编写 Ant Design 代码时使用这些知识。布局尽可能小，以容下更密集的信息。窗口打开时不要使用过渡动画，保持界面打开的流畅性。可以使用 loading 和 selekton 这里来优化界面在加载数据时的体验。
